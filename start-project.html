WARNING: Utilities like `curl` or `git` are not mentioned because this guide focuses on installing the Ada programming language and my framework, rather than the tools you might use to work with them. All examples here are shown for the x86_64 architecture. If you are using, for example, ARM64, then choose the packages for aarch64.

Install ada!

Before you can write code using the NEWELL framework, you will need to install the Ada language and the Alire build system/package manager. This is how it’s done.

Linux

Archlinux

sudo pacman -S gcc-ada # install gnat compiler.
git clone https://aur.archlinux.org/alire-bin # or alire and alire-git
cd alire-bin
makepkg -si
You can also use yay, aura, paru, or other AUR helpers. 
yay -S alire-bin
aura -A alire-bin
paru -S alire-bin
Or you can build it from source yourself. 
git clone --recurse-submodules https://github.com/alire-project/alire/
cd alire
ALIRE_OS=linux gprbuild -j0 -p -P alr_env.gpr -XALIRE_BUILD_MODE=release
mkdir -p ~/.local/bin/
cp bin/alr ~/.local/bin/
chmod +x ~/.local/bin/alr
export PATH="$HOME/.local/bin:$PATH

NixOS

nix-shell -p alire gnat gprbuild

or

nix profile install nixpkgs#alire nixpkgs#gnat nixpkgs#gprbuild

or add the packages to your /etc/nixos/configuration.nix (you can open it with sudo -e or doas using your favorite editor, such as Neovim):

environment.systemPackages = with pkgs; [
  alire
  gnat
  gprbuild
];

Then rebuild your configuration:

sudo nixos-rebuild switch

Windows

// I hate this system too.

Installing Alire

curl.exe -sLO https://github.com/alire-project/alire/releases/download/v2.1.1/alr-2.1.1-bin-x86_64-windows.zip
Expand-Archive -Path ".\alr-2.1.1-bin-x86_64-windows.zip" -DestinationPath "C:\Alire\" -Force

$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*C:\Alire\bin*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;C:\Alire\bin", "User")
}

Reload your terminal, then install the compiler (accept MSYS2 installation if prompted):

# Select gnat_native and gprbuild
alr toolchain --select

Testing

alr --version
alr toolchain
